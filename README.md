# University Event Management and Ticket System

A full-stack MERN (MongoDB, Express.js, React.js, Node.js) web application designed to manage university events, ticketing, and user registrations efficiently.

---

## 🛠️ Tech Stack

- **Frontend:** React.js, Vite, HTML5, CSS3, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Tools & Libraries:** Git/GitHub, Postman, JWT, Multer / Cloudinary

---

## 🚀 Getting Started

Follow these instructions to set up and run the project locally on your machine.

### Prerequisites
Make sure you have the following installed:
- [Node.js](https://nodejs.org/) (v16 or higher)
- [Git](https://git-scm.com/)
- [MongoDB](https://www.mongodb.com/) (Local or Atlas)
